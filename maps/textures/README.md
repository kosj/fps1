| 파일 접두어 | 에셋 | 용도 |
|---|---|---|
| asphalt_02 | https://polyhaven.com/a/asphalt_02 | 바닥 |
| cracked_concrete_wall | https://polyhaven.com/a/cracked_concrete_wall | 벽 |
| container_side | https://polyhaven.com/a/container_side | 높은 엄폐물(컨테이너) |
| plywood | https://polyhaven.com/a/plywood | 낮은 엄폐물(나무 상자) |
