# 에셋 품질 보완 계획 (Varco 메시)

## 진단 (실측)

Varco 출력 두 개(기둥 12,000 삼각형 / 캐릭터 100,000 삼각형)를 `tools/asset_pipeline/analyze.py`로 측정했다.

| 문제 | 측정값 | 게임에서의 영향 |
|---|---|---|
| 삼각형이 불규칙하게 흩어짐 | 평평한 면에도 삼각형이 빽빽함 | 같은 모양에 4배쯤 많은 삼각형, 웹/휴대폰에서 느림 |
| 각진 물체의 면이 울퉁불퉁 | 기둥 모서리가 물결침 | 총기·건물 같은 하드서피스에서 가장 티가 남 |
| UV가 잘게 쪼개짐 | 12,000 삼각형에 조각 176개 | 이음매, 텍스처 낭비, 밉맵 번짐 |
| 파일이 큼 | 11MB / 26MB (텍스처 2K~4K 3장) | 웹 로딩 시간 |
| 변형용 토폴로지 아님 | 관절에 엣지 루프 없음 | 캐릭터 애니메이션 때 관절이 찌그러짐 |

## 원칙

AI 메시는 **완성품이 아니라 하이폴리 조각**으로만 쓴다. 게임에 들어가는 메시는 새로 만들고,
원본의 색·요철은 텍스처로 구워 옮긴다. (생성 → 리토폴로지 → 베이크 → 엔진 검증)

## 종류별 방법

| 종류 | 최종 메시 | Varco의 역할 |
|---|---|---|
| 총기 (1인칭에서 화면 가까이 보임) | Blender 스크립트로 직접 모델링: 단면 돌출, 베벨, 면적 가중 노멀. 부품(탄창·노리쇠·슬라이드) 분리 | 컨셉 이미지, 텍스처 참고 |
| 맵 소품·건물 조각 | CC0 수작업 모델 우선, 없으면 Varco → `process.py --mode hard` | 하이폴리 원본 |
| 캐릭터 | Varco 고해상도(30만) → `process.py --mode organic`(QuadriFlow 쿼드) → 리깅 | 하이폴리 원본 |
| 바닥·벽 재질 | Poly Haven CC0 PBR | 사용 안 함 |

## 자동 파이프라인 (`tools/asset_pipeline/process.py`)

1. 정리: 중복 정점 병합, 부스러기 조각 제거, 구멍 메우기, 노멀 방향 통일
2. 리토폴로지: hard는 평면 병합 후 축소, organic은 QuadriFlow
3. 셰이딩: 각도 기준 샤프 엣지 + 면적 가중 노멀
4. 새 UV
5. 베이크: 원본 → 새 메시 (base color, normal, roughness)
6. 크기·원점 맞춤, GLB(JPEG 텍스처) 내보내기

검증 결과(기둥): 12,000 → 3,000 삼각형, 10.9MB → 0.94MB, 렌더 비교에서 겉모습 차이 거의 없음.

## 한계

- 실루엣 자체가 뭉개진 것은 베이크로 복구되지 않는다. 그래서 총기는 AI 메시를 쓰지 않는다.
- 자동 UV는 요철이 많은 면에서 조각이 많이 나온다. 가까이 보이는 에셋은 이음매를 직접 지정한다.
- 평면 병합은 길쭉한 삼각형을 만든다. 정적 소품에는 괜찮고, 변형되는 메시에는 쓰지 않는다.

## 합격 기준 (에셋을 넣기 전 `analyze.py`로 확인)

| 종류 | 삼각형 | 텍스처 | 파일 |
|---|---|---|---|
| 1인칭 총기 | 8,000 이하 | 1024 | 1.5MB 이하 |
| 3인칭 총기 | 1,500 이하 | 512 | 0.4MB 이하 |
| 캐릭터 | 12,000 이하 | 1024 | 2MB 이하 |
| 소품 | 3,000 이하 | 512~1024 | 1MB 이하 |

공통: 비매니폴드 엣지 0, 퇴화 삼각형 0, 음영·와이어 렌더를 눈으로 확인.
