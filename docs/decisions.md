# 기술 결정 기록

결정이 바뀌면 항목을 지우지 않고 아래에 새 항목을 추가합니다.

## 2026-11-26

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 엔진 | Godot 4.7, GDScript | Windows 화면 품질(Forward+), 텍스트 기반 씬, 라이선스 비용 없음. C#은 웹 내보내기가 안 됨 |
| 플랫폼 | Windows, 웹 | Windows가 기준 품질, 웹은 같은 게임의 가벼운 화면 프리셋 |
| 웹 렌더러 | Compatibility (WebGL 2) | Godot 4.7 웹 내보내기는 WebGL 2만 지원 |
| 게임 형태 | 6v6 멀티플레이 PvP (팀 데스매치, 점령전) | 콜 오브 듀티 멀티플레이를 레퍼런스로 함 |
| 1차 범위 | 맵 3개, 무기 8~10종, 봇 포함 | 좁은 범위를 높은 품질로 마감 |
| 세계관 | 근미래 밀리터리 (잠정) | 가상의 총기 디자인으로 실제 상표를 피하기 쉬움 |
| 네트워크 구조 | 전용 서버 권위, 클라이언트 예측, 지연 보상 | 웹 클라이언트는 코드가 노출되므로 서버 판정이 필수 |
| 물리 | Jolt Physics, 60Hz | 서버와 클라이언트가 같은 설정 사용 |
| 입력 액션 | 코드로 등록 (`game/core/input_setup.gd`) | project.godot의 직렬화 이벤트보다 변경 이력이 읽기 쉬움 |
| 스크립트 참조 | `preload` 상수 | 헤드리스 테스트가 전역 클래스 캐시에 의존하지 않게 함 |
| 3D 에셋 | Varco 3D 생성 → Blender 폴리싱 → GLB | Varco는 PRIVATE 라이선스로 생성 |
| 사운드 | ElevenLabs (효과음, 음성, 음악) | 유료 플랜에서 상업적 이용 |

## 미결정

- 서버 호스팅과 서비스 지역
- 수익 모델과 배포처
