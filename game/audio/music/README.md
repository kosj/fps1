# 음악

| 파일 | 출처 |
|---|---|
| menu_loop | `tools/audio/compose_menu.py`로 합성한 32초 반복(A 단조, 90 BPM: 현악 패드, 베이스 반복 음형, 북, 원형 잔향). 이음매가 없다 |
| victory / defeat | ElevenLabs 효과음(eleven_text_to_sound_v2)으로 만든 짧은 승리/패배 금관 소리(1~2초) |

ElevenLabs의 음악 길이 효과음은 30초에 300 크레딧이라 이번 달 남은 크레딧으로는 만들 수 없어 메뉴 음악은 직접 합성했다.
