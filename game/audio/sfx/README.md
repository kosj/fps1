# 효과음

ElevenLabs 효과음 생성(eleven_text_to_sound_v2)으로 만들고, 앞뒤 무음을 잘라 음량을 맞춘 뒤 OGG로 저장했다.

| 파일 | 내용 |
|---|---|
| shot_rifle / shot_smg / shot_shotgun / shot_sniper | 무기별 발사음 |
| reload | 탄창 결합음 |
| dry | 빈 총 격발음 |
| step | 아스팔트 위 군화 발소리 |
| impact | 콘크리트 탄착음 |
| ambience_yard | 야적장 배경음(바람, 먼 기계음). 1.4초 반복 |
