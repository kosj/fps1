# 아나운서 음성

ElevenLabs 음성 합성(eleven_flash_v2_5, 라이브러리 목소리 "Todd - Serious")으로 여덟 줄을 한 번에 읽힌 뒤,
말 사이의 무음을 찾아 줄마다 잘랐다. 저역 정리(90 Hz), 가벼운 압축, 음량 맞춤(-16 LUFS)을 했다.

| 파일 | 대사 | 쓰는 때 |
|---|---|---|
| start_tdm | Eliminate the enemy. | 팀전 시작 |
| start_dom | Secure the objectives. | 점령전 시작 |
| victory / defeat / draw | Victory. / Defeat. / Draw. | 판 결과 |
| zone_taken / zone_lost | Objective secured. / Objective lost. | 거점 주인이 바뀜 |
| one_minute | One minute remaining. | 남은 시간 1분 |
